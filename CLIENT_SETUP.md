# Установка на сервер — инструкция

Бот собирает посты из Telegram-каналов, переводит их на английский с обезличиванием и по вашей команде публикует в LinkedIn / X / Threads.

## Шаг 1. Подготовьте доступы (до установки)

Это делается один раз, примерно 20 минут. Все ключи заводятся на ваши аккаунты — вы их владелец.

**1. Телеграм-бот.** В Telegram напишите [@BotFather](https://t.me/BotFather):
- команда `/newbot` → придумайте имя и юзернейм → получите **токен** (длинная строка вида `8800949181:AAH...`);
- команда `/setprivacy` → выберите своего бота → нажмите **Disable** (без этого бот не сможет читать сообщения в группах).

**2. Ваш chat id.** Найдите своего бота в поиске Telegram, нажмите Start и отправьте `/id`. Бот ответит числом — это ваш **chat id**. (Работает после Шага 4, поэтому можно вернуться сюда позже.)

**3. Ключ OpenAI.** [platform.openai.com](https://platform.openai.com) → API keys → Create new secret key. Там же в разделе Billing поставьте месячный лимит — реальный расход около $1–3 в месяц.

**4. Buffer** — сервис, через который идёт публикация в соцсети. На [buffer.com](https://buffer.com) зарегистрируйтесь и подключите свои LinkedIn, X и Threads (бесплатный тариф позволяет ровно 3 канала). Затем [publish.buffer.com/settings/api](https://publish.buffer.com/settings/api) → создайте **API-ключ**.

**5. Список каналов** — Telegram-каналы, из которых берём контент, в формате `@username`.

## Шаг 2. Сервер

Любой VPS с Ubuntu 22.04/24.04, минимальной конфигурации достаточно (1 vCPU, 2 GB RAM, ~5 €/мес: Hetzner, DigitalOcean, Contabo).

Подключитесь по SSH и установите Docker:

```bash
apt update && apt install -y docker.io docker-compose-v2 git
```

## Шаг 3. Код

```bash
git clone <ССЫЛКА_НА_РЕПОЗИТОРИЙ> /opt/repost
cd /opt/repost
```

Если код передан архивом — распакуйте его в `/opt/repost`.

## Шаг 4. Настройка

```bash
cp .env.example .env
nano .env
```

Заполните обязательные строки (остальные можно не трогать):

| Строка | Что вписать |
|---|---|
| `BOT_TOKEN` | токен из пункта 1 |
| `OWNER_CHAT_ID` | ваш chat id из пункта 2 |
| `OPENAI_API_KEY` | ключ из пункта 3 |
| `BUFFER_ACCESS_TOKEN` | ключ из пункта 4 |
| `BUFFER_CHANNELS` | заполняется после Шага 5 |
| `AUTHOR_FACTS` | ваше имя, компания, чем занимаетесь — подставляется вместо чужих названий |
| `TIMEZONE` | ваш часовой пояс, например `Europe/Kyiv` |
| `POST_TIMES` | во сколько присылать посты, по умолчанию `09:00,14:00,19:00` |

Сохранить: `Ctrl+O`, `Enter`, выйти: `Ctrl+X`.

Список каналов:

```bash
nano sources.txt      # по одному @username на строку
```

## Шаг 5. Запуск

```bash
docker compose up -d --build
```

Узнать id ваших каналов в Buffer и дописать их в `.env`:

```bash
docker compose exec bot python -m repost.publisher --channels
```

Команда выведет строки вида `linkedin  6a64f84e...  Ваше имя`. Впишите их в `.env` одной строкой:

```
BUFFER_CHANNELS=linkedin:6a64f84e...,twitter:6a64f879...,threads:...
```

Перезапустите и загрузите историю каналов за 90 дней:

```bash
docker compose restart
docker compose exec bot python -m repost.webingest --days 90
```

## Шаг 6. Проверка

Напишите боту в Telegram `/next` — он предложит первый пост. Придёт два сообщения: оригинал с пометками, что было заменено, и готовый английский текст с кнопками.

- **✅ Да, пост** — публикует в подключённые соцсети
- **❌ Нет** — пропустить
- **✏️ Редактировать** — прислать свой текст, он станет финальным
- **🔁 Заново** — сгенерировать другой вариант

Команда `/stats` покажет, сколько постов собрано и сколько в очереди.

## Как это работает дальше

Ничего запускать не нужно, бот работает сам:

- **1-го числа каждого месяца** собирает новые посты из ваших каналов;
- **три раза в день** (по расписанию из `POST_TIMES`) присылает вам один готовый пост;
- если вы не ответили — пост пропускается, в следующий раз придёт новый;
- по кнопке публикует сразу во все подключённые соцсети.

## Полезные команды

```bash
docker compose logs --tail 50                              # что происходит
docker compose restart                                     # перезапустить
docker compose exec bot python -m repost.ingest status     # статистика базы
cp /opt/repost/data/repost.db /opt/repost/data/backup.db   # бэкап
```

## Если что-то не работает

- **Бот молчит** — `docker compose logs --tail 50`, обычно видно причину (неверный токен или ключ).
- **Ошибка при публикации** — проверьте, что каналы в Buffer подключены и id в `BUFFER_CHANNELS` актуальны.
- **Не приходят посты по расписанию** — проверьте `TIMEZONE` и `POST_TIMES` в `.env`, после правки `docker compose restart`.
- **Очередь пуста** — соберите свежие посты: `docker compose exec bot python -m repost.webingest --days 30`.
